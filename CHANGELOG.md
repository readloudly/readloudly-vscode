# Changelog

## 0.1.0

- Read a selection, file, cursor position, clipboard or any selected text in VS Code (Chat,
  terminal, hovers) with sentence and word highlight.
- Player controls above the clicked line or selection, with speed and voice.
- Device voices and on-device Kokoro voices, free; your text stays on the computer (Kokoro
  downloads its voice model once, pinned to one version).
- ReadLoudly voices after sign-in, with a credit estimate, shared-cache notice and a never-send
  list for secret files. Export as MP3.
- Summarize, Translate, Explain and Simplify and Listen through the VS Code language model,
  `@readloudly` in Chat and the `#readAloud` agent tool.
- Open in ReadLoudly Web, and a Get Started walkthrough.
