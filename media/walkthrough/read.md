# Read a selection

Select a few sentences in any file and press **Ctrl+Shift+Cmd+R** on macOS (**Ctrl+Shift+Alt+R** on Windows and Linux).

The sentence being read is highlighted, and the controls appear right above the line: Pause, Back, Next, Stop, Speed and Voice. Click any line to start reading from there.

The same shortcut reads selected text in Chat, the terminal, hovers and webviews.
